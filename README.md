# 天课计算器 v2 · Zakat Calculator

基于哈乃斐学派教法的现代化天课计算工具，采用伊斯兰几何艺术美学设计。

## 设计特点

- **美学风格**: 伊斯兰几何艺术 + 现代极简主义
- **配色方案**: 深青金石蓝 (#1a365d) + 金色点缀 (#d4af37) + 象牙白背景
- **字体组合**: Amiri (阿拉伯文) + Noto Serif SC (中文标题) + 系统无衬线字体（正文和界面文字）
- **装饰元素**: 几何图案背景、星形徽章、优雅的渐变效果

## 功能特性

- 🟡 **实时金银价格**: 自动获取国际黄金/白银价格并换算为人民币
- 💱 **元/万元单位切换**: 各卡片独立单位切换，方便不同量级录入
- 📋 **详细资产分类**: 现金、贵金属、股票基金、投资房产、应收账款
- 💳 **债务扣除**: 日常开支、各类贷款、信用卡等
- 💾 **草稿自动保存**: 金额统一以元保存，兼容旧草稿，单位切换与刷新不会重复换算
- 🧮 **起征点参考值**: 根据 612.36 克白银计算参考金额，由用户主动采用，允许自行修改
- 📱 **精简填写流程**: 贵金属、投资、债务按需展开，手机底部固定查看结果入口
- ✍️ **手动价格保留**: 自动获取不会覆盖手动价格，主动替换需确认；请求失败保留原值
- 📄 **清晰结果页**: 展示资产、扣除项、净资产、计算公式和起征点差额
- 🖨️ **打印友好**: 结果页支持直接打印

```
├── app.js              # 草稿、价格和表单交互

├── result.html         # 结果展示与打印
├── style.css           # 响应式样式
└── tests/              # 金额和浏览器回归检查
```

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

资产与计算结果使用 LocalStorage 保存在本机，不会上传。金银价格、汇率和字体通过外部服务获取。清空填写时会一并删除本机草稿与计算结果。

也可从仓库根目录运行 `python3 -m http.server 8000`，使用本地静态服务开发。

## 验证

从仓库根目录执行：

```sh
node --test tests/calculator.test.cjs
# 静态服务已启动，Python Playwright 与系统 Chromium 可用时：
python3 tests/browser_smoke.py
```

浏览器检查默认使用本地 8000 端口，覆盖旧草稿迁移、单位切换、手动价格、异步更新、起征点参考值、字段提示、结果页和手机布局。价格服务在该套检查中模拟；真实价格服务需另外验证。
